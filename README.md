# Game Đánh Bài

Game HTML/CSS/JavaScript chạy trực tiếp trong trình duyệt.

## Chạy bằng VS Code

1. Giải nén ZIP.
2. Mở thư mục `game-danh-bai` bằng VS Code.
3. Mở `index.html` bằng trình duyệt.
4. Hoặc cài extension **Live Server** trong VS Code rồi chọn **Open with Live Server**.

## Game
- Tiến lên miền Nam
- Liêng
- AI: Dễ / Bình thường / Khó

## Lưu ý
Đây là bản game offline. Tiền/xu chỉ tồn tại trong phiên chơi hiện tại.
